1. Clone the [noScribe Editor](https://github.com/kaixxx/noScribeEditor) (HTML: `https://github.com/kaixxx/noScribeEditor.git`; SSH: `git@github.com:kaixxx/noScribeEditor.git`) directly into this folder.
2. The requirements for noScribe and noScribeEditor needs to be manually copied to the `{cpu|cuda}/requirements` folder as `requirements_nS.txt` and `requirements_nSE.txt`.
3. The spec file needs to be manually copied to the `{cpu|cuda}/spec_files` folder as `noScribe.spec`.
4. `cd` into `{cpu|cuda}` and run `./command.sh`.
